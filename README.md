# Overpriced Calculator

*A simple calculator with an intentionally absurd business model.*

## Overview

**Overpriced Calculator** is a small experimental web project built for fun and as a way to practice coding.

The concept is simple: enter a mathematical expression, press the equals button, and instead of getting the result, you are presented with a message explaining that your calculation is extremely complex and requires significant computing resources.

The solution? Upgrade to a premium subscription through Stripe.

Yes, you have to pay to solve a calculation.

## How It Works

1. **Enter a calculation** — Type a mathematical expression into the calculator.
2. **Press equals** — Instead of displaying the result, the application presents an exaggerated message about the computational resources required.
3. **Unlock the solution** — Click the subscription button to access the Stripe checkout page.
4. **Discover the business model** — Pay for the privilege of solving a calculation.

The entire concept is intentionally overengineered for something that should be completely free.

## Design & Interface

I wanted to create an interface that felt clean, modern, and enjoyable to use, even though the concept itself is deliberately ridiculous.

The visual direction focuses on:

- **Pastel colors** — A soft, pinkish color palette that gives the interface a light and distinctive look.
- **Liquid Glass aesthetics** — Subtle glass-like effects that add depth and a modern feel to the interface.
- **Minimalist design** — A simple layout that keeps the calculator at the center of the experience.
- **Interactive elements** — A user flow that connects the calculator interface to the subscription experience.

The goal was to experiment with interface design and create something visually appealing without making it unnecessarily complicated.

## Technologies & Concepts

This project explores several aspects of web development and AI-assisted programming.

- **Web Development** — Building an interactive website and implementing user interactions.
- **AI-Assisted Coding** — Using AI to help generate code, explore implementation ideas, and understand how different parts of an application work.
- **Stripe Integration** — Experimenting with subscription-based billing, recurring payments, and the checkout process.
- **UI/UX Design** — Exploring minimalist layouts, pastel colors, and Liquid Glass-inspired visual effects.

## Why I Built It

This project was created primarily as a coding experiment, not as a serious commercial product.

My main goals were to:

- Practice building an interactive web application from an idea.
- Experiment with modern interface design and visual effects.
- Learn how subscription-based payment systems work through Stripe.
- Improve my ability to analyze, understand, and modify AI-generated code.
- Explore how AI can accelerate the development process while still requiring an understanding of the underlying implementation.

I wanted to build something small, functional, and slightly absurd while learning practical skills that could be applied to more ambitious projects.

## Project Status

This is an experimental project developed for educational and entertainment purposes.

It is not intended to be a production-ready calculator or a serious subscription service. The exaggerated computational requirements and pricing concept are part of the joke.

## What I Learned

Through this project, I explored the process of turning an idea into an interactive website, designing a coherent visual identity, and experimenting with an external payment platform.

It also provided an opportunity to practice AI-assisted development, with a focus on understanding the generated code rather than simply using it without analysis.

## Disclaimer

The claims about computational complexity are fictional and part of the concept. The project is intended for learning and experimentation, not as a genuine paid computational service.
